# Multi-AI-Agent-using-Langgraph
This shows the steps required to create a multi-ai agent using langgraph and open source LLM model.
In this Multi- Ai Agent, open source Groq llm is used using Openai 120b model which is a light weight model. This agents teaches how to create router and add vectordb using astrdb cloud so that it can be deployed on aws and also create wiki search which is another agent so that the user query can be routed on either of the agent as per the query.
